🚀 QUICK START (3 COMMANDS)

1. chmod +x panorama_to_terraform.py quick_start.sh
2. ./quick_start.sh
3. cd terraform_example && terraform init

💻 BASIC USAGE

# Convert your Panorama config
python3 panorama_to_terraform.py your_config.xml

# Specify output directory
python3 panorama_to_terraform.py your_config.xml --output-dir ./terraform

# Get help
python3 panorama_to_terraform.py --help

Web UI:     Device → Setup → Operations → Save config snapshot
CLI:        set cli config-output-format xml; configure; show
API:        curl -k 'https://panorama/api/?type=export...'

🔐 TERRAFORM DEPLOYMENT

1. Create terraform.tfvars:
   panos_hostname = "panorama.example.com"
   panos_username = "admin"
   panos_password = "password"
   device_group   = "Production"

2. Initialize:    terraform init
3. Plan:          terraform plan
4. Apply:         terraform apply

🔧 COMMON ISSUES & FIXES

Issue: XML Parse Error
Fix:   Re-export from Panorama, ensure complete file

Issue: Authentication Failed  
Fix:   Check credentials, verify API access enabled

Issue: Duplicate Resources
Fix:   Script auto-deduplicates, check original config

Issue: Missing Resources
Fix:   Verify device group permissions
