# Sample converter output

The canonical example output is the golden sample: `tests/golden/sample/`.
It is generated from `sample_panorama_config.xml` and pinned
byte-for-byte by `tests/test_golden_files.py`, so it cannot drift from
what the converter actually writes.

Regenerate it locally:

```bash
python3 panorama_to_terraform.py sample_panorama_config.xml \
    --output-dir terraform_example
```

A larger fixture with more object types (decryption and PBF rules,
zones, interfaces, virtual routers, VPN) is
`tests/fixtures/kitchen_sink.xml`; its output set is pinned under
`tests/golden/kitchen_sink/`.
