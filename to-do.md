## Rules the layout keeps

- `docs/ARCHITECTURE.md` §1.1 is the owner document for the layout. `AGENTS.md` names the tracking markdown
  set, and each index names every document under it, so a file outside an index is a finding.
- Import rule: `src/` is one flat namespace, so a module in `src/` imports its siblings by plain name and no
  module builds a path. `pyproject.toml` `pythonpath = ["src"]` is the only place a test path is stated, and
  a run gets the same namespace from Python's script-directory rule, so no entry point adds path code. No
  module, test or script states a second path rule.
- Test-layout rule: `tests/` is flat. The test files sit beside `fixtures/` and `golden/`, and
  `tests/conftest.py` is the one shared helper file, so the layout does not change again.
  `pyproject.toml` `testpaths = ["tests"]` keeps discovery at the root.

## Rules the write path keeps

- One function writes a file (`src/write_path.py`), so the LF rule is enforced once (`ARCHITECTURE.md` §6), and the
  two path builders name the two sets. No module writes a file outside it. The record directory is the output
  directory, so the prune action reads the record file the same run wrote and no record directory exists.
- The gate reads the `.tf` files for the block rules and the four records read by the data rule; the two file sets
  stay distinct. A new file shape must name which set it belongs to.
- One place decides the shape of a value (`resource_mapping.VALUE_VARIABLES`) and one place decides the shape of
  a reference field (`TerraformGenerator.name_ref`); the write path applies them per unit and defines no second
  rule.
- One place states the scope facts (`container_coverage.SCOPE_FACT_KEYS`) and one place states the unit set
  (`unit_manifest.units`), so the identity join, the level order, and the order chain read the same order.
  `reference_edges.LEVEL_KEYS` is `unit_manifest.NAME_LEVELS` reversed, without the virtual system.
- The §5 naming rule lives in `naming.py`; the data modules take it as an argument.
- A per-unit file names its unit only by its directory, so no per-unit file states a path in its bytes, and a
  gate finding names the path from the codebase root.
- The data rule reads the records at the codebase root only, as one rule over the rows of every unit. No rule
  reads a report, `README.md` or `SOURCE.txt`. No flag names the layout, and the exit codes are unchanged.
- A cycle test needs two units that each declare a name the other one uses, because the reference rule resolves
  only inside the referrer's own unit (`tests/test_reference_edges.py`, `tests/fixtures/reference_cycle.xml`).
- A golden set is the bytes of a real run. It is regenerated by a run and never edited by hand, so a fact
  change moves the digests, the block names, and the action addresses in the same commit.
